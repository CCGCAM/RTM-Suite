toolsrtm.fluspect
===================

FLUSPECT-B / FLUSPECT-B-Cx leaf model: PROSPECT reflectance/transmittance
plus chlorophyll-fluorescence excitation-emission matrices. Direct port
of ``ToolsRTM/R/fluspect_B.R`` (``getFluspect.B``) and ``fluspect_Cx.R``
(``getFluspect.Cx``).
