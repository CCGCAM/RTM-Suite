toolsrtm

Leaf optics (PROSPECT-D, PROSPECT-PRO), leaf-angle distributions, canopy BRDF models (fourSAIL, fourSAIL2, INFORM), spectral vegetation indices, soil reflectance models (MARMIT-1, BSM for SPART), sensor convolution, and trait inversion (classical ML and, optionally, deep learning).
