# computes non conservative scattering conditions

computes non conservative scattering conditions

## Usage

``` r
NonConservativeScattering(m, lai, att, sigb, ks, ko, sf, sb, vf, vb, tss, too)
```

## Arguments

- m:

  numeric.

- lai:

  numeric. Leaf Area Index

- att:

  numeric.

- sigb:

  numeric.

- ks:

  numeric.

- ko:

  numeric.

- sf:

  numeric.

- sb:

  numeric.

- vf:

  numeric.

- vb:

  numeric.

- tss:

  numeric.

- too:

  numeric.

## Value

list. tdd, rdd, tsd, rsd, tdo, rdo, rsod
