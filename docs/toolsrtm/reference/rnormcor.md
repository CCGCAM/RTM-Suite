# Generate a single variable from a distribution correlated with another distribution

Allow user to draw from a random normal distribution correlated with a
user specified distribution

## Usage

``` r
rnormcor(x, rho)
```

## Arguments

- x:

  variable to draw from

- rho:

  correlation coefficient between x and result of function

## Value

a single numeric value drawn from a normal distribution correlated with
x at the level of rho
