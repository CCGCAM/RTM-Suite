# Extract acquisition dates from a set of TIFF file names

Extract acquisition dates from a set of TIFF file names

## Usage

``` r
extract_dates_from_tiff_files(tiff_files)
```

## Arguments

- tiff_files:

  character vector. File paths or names containing a date in either
  `YYYY-MM-DD` or `YYYYMMDD` format, which will be extracted via regular
  expression.

## Value

dates
