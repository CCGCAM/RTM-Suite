# get random plant traits using a uniform distribution

get random plant traits using a uniform distribution

## Usage

``` r
get_data(RTmodel = "PROSPECT-D", nLUT = 100, random.input = 100)
```

## Arguments

- RTmodel:

  RT model: options are: 'PROSPECT-PRO';'PROSPECT-D'; 'INFORM'; and
  'fourSAILH'

- nLUT:

  nummber of combinations

- random.input:

  the seed number for the uniform distribution

## Value

a LUT
