# Extract all bands from SE images (adapted to NETCDF dataset)

Extract all bands from SE images (adapted to NETCDF dataset)

## Usage

``` r
getTIFFs(netCDFs = NULL, bands = NULL, output = NULL, pattern = NULL)
```

## Arguments

- netCDFs:

  path with the Netcdf

- bands:

  a vector with the names of the inputs of the NetCDF

- output:

  path of the outputs

- pattern:

  File pattern to extract the netcdf (Area or studied region)

## Value

tiffs
