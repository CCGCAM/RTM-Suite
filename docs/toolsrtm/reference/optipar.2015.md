# Fluspect specific absorption coefficients (2015 parameterisation)

Updated Fluspect coefficient table (Vilfan et al. 2016 parameterisation)
used by the mSCOPE/Fluspect-CX fluorescence model path.

## Usage

``` r
optipar.2015
```

## Format

A data frame with 2001 rows (400-2400 nm) and 15 columns including
wavelength (`wl`), refractive index (`nr`), specific absorption
coefficients (`Kab`, `Kcar`, `Ks`, `Kw`, `Kdm`, `nw`), fluorescence
basis spectra (`flu1`, `flu2`), three generalised soil vectors
(`GSV1`-`GSV3`) and violaxanthin/zeaxanthin carotenoid coefficients
(`KcaV`, `KcaZ`).
