# Get LUTs for radiative transfer models

Get LUTs for radiative transfer models

## Usage

``` r
getLUTs(inputs = NULL, nLUT = 100, dependencies = "Car", setseed = 123)
```

## Arguments

- inputs:

  a LUT table with variables with specific ranges.

- nLUT:

  the number of rows for the LUT

- dependencies:

  nLUT the number of rows for the LUT

- setseed:

  setseed a seed number to contral random process. By default is FALSE
  or null. Please add the number.

## Value

a dataframe with all parameters
