# Computation of transmissivity of a dielectric plane surface, averaged over all directions of incidence and over all polarizations.

Computation of transmissivity of a dielectric plane surface, averaged
over all directions of incidence and over all polarizations.

## Usage

``` r
calctav(alpha, nr)
```

## Arguments

- alpha:

  numeric. Maximum incidence angle defining the solid angle of incident
  light

- nr:

  numeric. refractive index (for PROSAIL)

## Value

numeric. Transmissivity of a dielectric plane surface
