# Generate plot for CARSPLS analysis.

This function generates a plot for the results of Competitive Adaptive
Reweighted Sampling (CARS) for partial least squares (PLS) analysis.

## Usage

``` r
get.plot.cars.pls(CARS)
```

## Arguments

- CARS:

  An object returned by the [`get.cars.pls`](get.cars.pls.md) function.

## Value

A plot representing the results of the CARSPLS analysis.
