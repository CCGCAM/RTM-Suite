# Simpson integration

Simpson integration

## Usage

``` r
Sint(y, x)
```

## Arguments

- y:

  must be any vector (rows, columns), but of the same length

- x:

  must be any vector (rows, columns), but of the same length; must be a
  monotonically increasing series develope by WV Jan. 2013, for SCOPE
  1.40

## Value

int
