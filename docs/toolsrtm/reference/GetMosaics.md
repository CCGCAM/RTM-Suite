# Get a Mosaic from TIFFs Tiles from (Forest type 2018 later from COPERNICUS)

Get a Mosaic from TIFFs Tiles from (Forest type 2018 later from
COPERNICUS)

## Usage

``` r
GetMosaics(ForestLayers = NULL, shapeLayer = NULL, output = NULL, proj = 3035)
```

## Arguments

- ForestLayers:

  path with the tiles

- shapeLayer:

  a shapefile format with the extension of the study region

- output:

  path to write the forest mask

- proj:

  projection, by default 3035

## Value

a mosaic
