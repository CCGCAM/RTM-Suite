# Get LUT for radiative transfer models

Get LUT for radiative transfer models

## Usage

``` r
getLUT_liberty(inputs = NULL, nLUT = 100, setseed = 123)
```

## Arguments

- inputs:

  a table with the specific ranges, type of distribution ...

- nLUT:

  the number of rows for the LUT

- setseed:

  integer, random seed used when sampling the LUT (default 123)

## Value

a dataframe with all parameters
