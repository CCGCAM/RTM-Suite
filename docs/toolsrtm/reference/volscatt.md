# Compute volume scattering functions and interception coefficients for given solar zenith, viewing zenith, azimuth and leaf inclination angle.

\#' edit 2017 12 28:

## Usage

``` r
volscatt(tts, tto, psi, ttl)
```

## Arguments

- tts:

  numeric. solar zenith

- tto:

  numeric. viewing zenith

- psi:

  numeric. azimuth

- ttl:

  numeric. leaf inclination angle

## Value

res list. includes chi_s, chi_o, frho, ftau
