# get the variables needed in temp_response_biochem

get the variables needed in temp_response_biochem

## Usage

``` r
define_temp_response_biochem(getTDP = T)
```

## Arguments

- getTDP:

  is TRUE get a list with TDP

## Value

get a list with all parameters for TDP

## Examples

``` r
TDP <- define_temp_response_biochem(getTDP = TRUE)
```
