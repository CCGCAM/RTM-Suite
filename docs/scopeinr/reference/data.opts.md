# Default SCOPE run options

Default values for the SCOPE model run-time options (equivalent to
`setoptions.csv`), controlling which radiative transfer/energy
balance/output modules are enabled.

## Usage

``` r
data.opts
```

## Format

A data frame with one row per option and a `Value` column.

## Source

Yang, P., E. Prikaziuk, W. Verhoef, and C. van der Tol. 2020.
Geoscientific Model Development Discussions.
