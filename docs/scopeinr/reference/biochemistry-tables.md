# Biochemical model lookup tables for Vcmax25/Jmax temperature response

Lookup tables of the temperature-response parameters used by the
biochemical (photosynthesis) model to scale maximum carboxylation
(`Vcmax25`) and electron transport (`Jmax`) capacity with leaf
temperature.

## Usage

``` r
table_Vcmax_

table_Jmax_
```

## Format

A data frame of temperature-response coefficients.

An object of class `data.frame` with 7 rows and 2 columns.
